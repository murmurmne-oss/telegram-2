## 🚀 ПЕРВЫЙ ЗАПУСК

### Шаг 1: Получение прав администратора

**Через базу данных:**
```sql
-- Подключиться к PostgreSQL
psql -U postgres -d telegram_courses

-- Найти своего пользователя по Telegram ID
SELECT * FROM users WHERE "telegramId" = 'ВАШ_TELEGRAM_ID';

-- Назначить роль ADMIN
UPDATE users 
SET role = 'ADMIN' 
WHERE "telegramId" = 'ВАШ_TELEGRAM_ID';

-- Проверить
SELECT id, name, role FROM users WHERE role = 'ADMIN';
```

**Через API (если у вас есть SUPER_ADMIN):**
```bash
curl -X PUT http://localhost:3001/api/admin/users/USER_ID/role \
  -H "Content-Type: application/json" \
  -d '{"role": "ADMIN"}'
```

### Шаг 2: Вход в админ-панель

1. Открой приложение: `http://localhost:5173`
2. Перейди в админ-панель: `http://localhost:5173/admin`
3. Если есть права ADMIN - увидишь Dashboard
4. Если нет - получишь ошибку доступа

## 📝 СОЗДАНИЕ ПЕРВОГО КУРСА

### Способ 1: Через Web интерфейс (рекомендуется)

#### Шаг 1: Открыть форму создания

```
URL: http://localhost:5173/admin/courses/new
```

Или:
1. Перейти в админ-панель → Courses
2. Нажать кнопку **"+ Создать курс"**

#### Шаг 2: Заполнить основную информацию

**Обязательные поля:**

1. **Название курса** (title)
   - Пример: "Азбука сексуального образования"
   - Макс. 100 символов
   - Должно быть уникальным

2. **Короткое описание** (shortDescription)
   - Пример: "Базовый курс о сексуальном здоровье"
   - 150-200 символов
   - Отображается в карточке курса

3. **Полное описание** (description)
   - Детальное описание курса
   - Markdown поддерживается
   - Можно добавить:
     - Что вы узнаете
     - Для кого этот курс
     - Требования

4. **Категория** (category)
   - Выбрать из списка:
     - Сексуальное образование
     - Отношения
     - Здоровье
     - Психология
     - Коммуникация

5. **Уровень сложности** (level)
   - BEGINNER (Начинающий)
   - INTERMEDIATE (Средний)
   - ADVANCED (Продвинутый)

6. **Цена** (price)
   - В рублях (например: 2990)
   - Для бесплатного курса: 0
   - Можно указать цену со скидкой

7. **Цена со скидкой** (discountPrice) - опционально
   - Если есть акция
   - Должна быть меньше основной цены
   - Пример: 2990 → 1990

#### Шаг 3: Загрузить обложку

**Требования к изображению:**
- Формат: JPG, PNG
- Размер: макс 5 MB
- Рекомендуемые размеры: 1200x630 px
- Соотношение сторон: 16:9

**Как загрузить:**
1. Нажать "Загрузить обложку"
2. Выбрать файл с компьютера
3. Подождать загрузки
4. Проверить превью

**Или указать URL:**
```
https://i.postimg.cc/hvSQcWwL/course-cover.png
```

#### Шаг 4: Дополнительные параметры

**Превью видео** (trailerUrl) - опционально
- YouTube URL: `https://youtube.com/watch?v=...`
- Vimeo URL: `https://vimeo.com/...`
- Показывается на странице курса

**Slug** - автоматически
- Генерируется из названия
- Пример: "azbuka-seksa" из "Азбука Секса"
- Можно изменить вручную

**Теги** - опционально
- До 5 тегов через запятую
- Пример: "здоровье, образование, wellness"
- Используются для поиска

#### Шаг 5: Сохранить

**Две кнопки:**

1. **"Сохранить черновик"** (Draft)
   - Курс НЕ виден пользователям
   - Можно редактировать
   - Статус: `isPublished: false`

2. **"Опубликовать"** (Publish)
   - Курс ВИДЕН всем пользователям
   - Появится в каталоге
   - Статус: `isPublished: true`

## 🎥 УПРАВЛЕНИЕ УРОКАМИ

### Добавление урока к курсу

#### Через Web интерфейс:

1. Открыть курс в админ-панели
2. Прокрутить до секции "Уроки"
3. Нажать **"+ Добавить урок"**

**Заполнить форму:**

**Обязательные поля:**

1. **Название урока** (title)
   - Пример: "Урок 1: Введение"
   - Краткое и понятное

2. **Описание урока** (description)
   - Что узнает студент
   - Ключевые моменты
   - Markdown поддерживается

3. **Видео URL** (videoUrl)
   - Варианты:
     - YouTube: `https://youtube.com/watch?v=...`
     - Vimeo: `https://vimeo.com/...`
     - Прямая ссылка: `https://example.com/video.mp4`

4. **Длительность** (duration)
   - В минутах
   - Пример: 25 (для 25 минут)
   - Отображается в списке уроков

5. **Порядковый номер** (order)
   - От 1 и выше
   - Автоматически инкрементируется
   - Можно менять drag-and-drop

**Опциональные поля:**

6. **Бесплатный preview** (isFree)
   - Чекбокс
   - Если включен - урок доступен всем
   - Используется для демо

7. **Дополнительные материалы** (materials)
   - PDF файлы
   - Ссылки на ресурсы
   - Шаблоны и чек-листы

#### Через API:

```bash
curl -X POST http://localhost:3001/api/admin/courses/COURSE_ID/lessons \
  -H "Content-Type: application/json" \
  -H "Authorization: Bearer YOUR_TOKEN" \
  -d '{
    "title": "Урок 1: Введение",
    "description": "Знакомство с курсом",
    "videoUrl": "https://youtube.com/watch?v=...",
    "duration": 25,
    "order": 1,
    "isFree": true
  }'
```

### Изменение порядка уроков

**Drag and Drop:**
1. Открыть курс в админке
2. Секция "Уроки"
3. Перетащить урок вверх/вниз
4. Нажать "Сохранить порядок"

**Вручную:**
```bash
curl -X PUT http://localhost:3001/api/admin/lessons/LESSON_ID \
  -H "Content-Type: application/json" \
  -d '{"order": 2}'
```

### Удаление урока

⚠️ **ВНИМАНИЕ:** Удаление необратимо!

1. Открыть курс
2. Найти урок
3. Нажать "Удалить" (иконка корзины)
4. Подтвердить удаление

## 👥 УПРАВЛЕНИЕ ПОЛЬЗОВАТЕЛЯМИ

### Просмотр пользователей

```
URL: http://localhost:5173/admin/users
```

**Таблица показывает:**
- Имя и username из Telegram
- Email (если есть)
- Роль (USER, ADMIN, SUPER_ADMIN)
- Дата регистрации
- Количество купленных курсов
- Статус (активен/заблокирован)

### Изменение роли пользователя

**Доступные роли:**

1. **USER** (по умолчанию)
   - Может покупать курсы
   - Смотреть уроки
   - Оставлять отзывы

2. **ADMIN**
   - Все права USER
   - Создавать/редактировать курсы
   - Управлять уроками
   - Просматривать статистику

3. **SUPER_ADMIN**
   - Все права ADMIN
   - Управлять пользователями
   - Менять роли
   - Блокировать пользователей

**Как изменить роль:**

**Web интерфейс:**
1. Перейти в Users
2. Найти пользователя
3. Кликнуть на роль
4. Выбрать новую роль из dropdown
5. Подтвердить

**API:**
```bash
curl -X PUT http://localhost:3001/api/admin/users/USER_ID/role \
  -H "Content-Type: application/json" \
  -d '{"role": "ADMIN"}'
```

### Блокировка/разблокировка

**Заблокировать:**
```bash
curl -X PUT http://localhost:3001/api/admin/users/USER_ID/block \
  -H "Content-Type: application/json" \
  -d '{"isBlocked": true, "reason": "Нарушение правил"}'
```

Заблокированный пользователь:
- Не может войти в приложение
- Не может покупать курсы
- Не может смотреть уроки

## 🎟️ ПРОМОКОДЫ И СКИДКИ

### Создание промокода

```
URL: http://localhost:5173/admin/promo-codes
```

#### Шаг 1: Нажать "Создать промокод"

#### Шаг 2: Заполнить форму

**Основные параметры:**

1. **Код** (code)
   - Пример: `SUMMER2024`, `FIRST50`
   - Уникальный
   - Только заглавные буквы и цифры
   - 4-20 символов

2. **Тип скидки** (discountType)
   - **PERCENTAGE** - процент (например, 20%)
   - **FIXED** - фиксированная сумма (например, 500 руб)

3. **Значение** (discountValue)
   - Для PERCENTAGE: от 1 до 100
   - Для FIXED: сумма в рублях

4. **Срок действия** (validFrom, validUntil)
   - Дата начала
   - Дата окончания
   - Или "Без ограничений"

5. **Максимум использований** (maxUses)
   - Сколько раз можно использовать
   - Или "Неограниченно" (null)

6. **Применимость** (applicableToAllCourses)
   - Все курсы
   - Или выбрать конкретные курсы

#### Примеры промокодов:

**1. Скидка 20% на все курсы:**
```json
{
  "code": "SALE20",
  "discountType": "PERCENTAGE",
  "discountValue": 20,
  "validFrom": "2024-01-01",
  "validUntil": "2024-12-31",
  "maxUses": null,
  "applicableToAllCourses": true
}
```

**2. Фиксированная скидка 500₽:**
```json
{
  "code": "FIRST500",
  "discountType": "FIXED",
  "discountValue": 500,
  "maxUses": 100,
  "applicableToAllCourses": true
}
```

**3. Скидка на конкретный курс:**
```json
{
  "code": "SEXEDU50",
  "discountType": "PERCENTAGE",
  "discountValue": 50,
  "applicableToAllCourses": false,
  "courseIds": ["course-id-1"]
}
```

### Статистика использования

**Посмотреть:**
- Сколько раз использован промокод
- Кто использовал
- Общая сумма скидок
- Доход с промокодом

## ❓ FAQ

### Как создать бесплатный курс?

При создании курса укажите `price: 0`

### Как сделать урок доступным для всех (preview)?

При создании урока включите чекбокс **"Бесплатный preview"** (`isFree: true`)

### Как загрузить видео?

Приложение НЕ хранит видео. Используйте:
1. **YouTube** - загрузите видео на YouTube (unlisted или public)
2. **Vimeo** - загрузите на Vimeo
3. **Облачное хранилище** - загрузите и получите прямую ссылку

Затем вставьте URL в поле "Видео URL"

### Как изменить цену курса?

1. Перейти в Admin → Courses
2. Найти курс
3. Кликнуть "Редактировать"
4. Изменить цену
5. Сохранить

⚠️ **Внимание:** Изменение цены влияет только на новые покупки. Студенты, которые уже купили курс, сохраняют доступ.

### Как удалить курс?

⚠️ **ОСТОРОЖНО:** Удаление необратимо!

1. Admin → Courses
2. Найти курс
3. Кнопка "Удалить" (красная иконка)
4. Подтвердить удаление

**Что произойдет:**
- Курс удалится из базы
- ВСЕ уроки удалятся
- Студенты потеряют доступ
- История покупок сохранится

**Альтернатива:** Снять публикацию (`isPublished: false`) - курс скроется, но данные сохранятся.

### Как вернуть деньги студенту?

```bash
curl -X POST http://localhost:3001/api/admin/purchases/PURCHASE_ID/refund \
  -H "Content-Type: application/json" \
  -d '{"reason": "Причина возврата"}'
```

Или через админ-панель:
1. Admin → Purchases
2. Найти покупку
3. "Возврат средств"

### Как экспортировать список студентов?

```bash
# Получить всех пользователей
curl http://localhost:3001/api/admin/users > users.json

# Фильтр по курсу
curl http://localhost:3001/api/admin/courses/COURSE_ID/students > students.json
```

### Как изменить длительность курса?

Длительность рассчитывается автоматически:
```
duration = сумма длительностей всех уроков
```

Чтобы изменить - измените длительность уроков.

### Как добавить сертификаты?

Сертификаты генерируются автоматически при завершении курса (100% прогресс).

**Настройка шаблона:**
1. Редактировать `backend/src/utils/certificate-generator.ts`
2. Изменить дизайн сертификата
3. Перезапустить backend

## 🔧 РЕШЕНИЕ ПРОБЛЕМ

### Курс не отображается в каталоге

**Проверить:**
1. `isPublished: true`?
2. Есть ли хотя бы 1 урок?
3. Указана ли обложка?
4. Цена указана корректно?

### Видео не воспроизводится

**Проверить:**
1. URL правильный?
2. Видео доступно (не private)?
3. HTTPS (не HTTP)?
4. Формат поддерживается?

### Студент не видит купленный курс

**Проверить:**
1. Статус покупки: `COMPLETED`
2. userId совпадает?
3. Курс не удален?
4. Пользователь не заблокирован?

### Промокод не работает

**Проверить:**
1. Срок действия не истек?
2. Лимит использований не превышен?
3. Применим к данному курсу?
4. Код написан правильно (case-sensitive)?
